# 实验设计与可复核约束

## 目标、变量与比较

任务为英文电影评论二分类。输入为正文，输出0（负面）或1（正面）。自变量为分类算法，控制变量为数据清洗、训练/测试边界、TF-IDF、CV划分及评分标准。三个模型搜索次数一致，但训练成本仍不同，不要求耗时相同。

假设：正文词汇和相邻词组含有可用于情感判别的信息，三个分类器应优于多数类基线。模型孰优由实际运行验证，不预先写定性能。

## 数据质量与拆分

评分标签仅用于读取和审计，不能进入模型。清洗不依据情感标签修改词汇。矛盾标签处理只在各自划分内执行；训练集不依赖测试标签清洗。跨划分仅依据规范化正文哈希移除测试重复。该审计涉及测试文本分布，但不将其统计拟合入特征或模型；清理后不再是原始排行榜测试集。

训练文本固定完成3折分层CV。每个候选的 Pipeline 在当前训练折重新拟合词表与IDF，再对验证折评分。模型和参数由训练CV选定。每种模型选定参数后用全部训练文本重拟合，持久化模型，然后一次性评估独立测试文本。

## 指标与解释

- Accuracy = 正确条数 / 总条数。
- 正面 Precision = TP/(TP+FP)，Recall = TP/(TP+FN)，F1 = 2PR/(P+R)。
- Macro-F1 = (负类F1 + 正类F1)/2，适合同时约束两类表现。
- ROC-AUC：以正面概率或决策分数作排序，观察不同阈值下的表现。
- 混淆矩阵：行真实，列预测，标签顺序[0,1]。
- Bootstrap：固定训练模型，重采样测试评论1000次，计算百分位区间；模型之间用相同索引进行配对比较。

交叉验证报告每个候选每折评分、均值及标准差。测试集报告分数及准确率CI。CV标准差和测试CI回答不同的问题，不能相互替代。

## 性能、资源与失败策略

默认 n_jobs=1，限制训练BLAS线程为1，稀疏TF-IDF用float32；在普通笔记本上减少多进程内存副本。模型不收敛时立即报错，不隐藏警告生成结论。网络请求设置超时，自动重试429/5xx；分段体下载失败最多重试3次并验证范围/长度，避免不完整缓存被误用。

本地服务只绑定127.0.0.1，只提供生成报告与预测。加载本项目训练的joblib模型，不能把未知来源模型文件放入模型目录。交互推理拒绝空文本、超长文本及没有已知英文特征的输入。

## 可复现产物

data_audit.json记录每一步移除数量；cv_*.csv保留候选及逐折指标；selection.json记录CV模型选择；metrics.json记录完整结果和实际环境；test_predictions.csv.gz记录每条测试预测；error_examples.csv保留部分误判；所有图表由这些产物生成。
